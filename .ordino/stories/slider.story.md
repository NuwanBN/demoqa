# Intent

A user can open Slider, change the slider value, and see the displayed value update.

# Acceptance Criteria

- [ ] AC-1: Moving the slider updates the displayed value

# Scenarios

## Change Slider Value [AC-1]

- User opens Slider
- User sets the slider to a target value
- The display field shows the same value
