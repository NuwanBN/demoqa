# Intent

A user can open Menu and hover main items to reveal submenu and sub-submenu entries.

# Acceptance Criteria

- [ ] AC-1: Main Item 1, Main Item 2, and Main Item 3 are visible
- [ ] AC-2: Hovering Main Item 2 shows its submenu entries
- [ ] AC-3: Hovering SUB SUB LIST » shows Sub Sub Item 1 and Sub Sub Item 2

# Scenarios

## Main Menu Items [AC-1]

- User opens Menu
- Main Item 1, Main Item 2, and Main Item 3 are visible

## Submenu On Hover [AC-2]

- User opens Menu
- User hovers Main Item 2
- Sub Item entries and SUB SUB LIST » are visible

## Sub Submenu On Hover [AC-3]

- User opens Menu
- User hovers Main Item 2
- User hovers SUB SUB LIST »
- Sub Sub Item 1 and Sub Sub Item 2 are visible

# Out of Scope

- Other Widgets
- Select Menu
